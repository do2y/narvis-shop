- 이벤트 처리(`chatEventHandler`)·세션(`sessionCoordinator`)·파서(`streamChat`)는 각각 테스트가 있음

  사용자에게 바로 보이는 결함이 여기서 남
- 상세는 [01-plan.md](01-plan.md) §1
