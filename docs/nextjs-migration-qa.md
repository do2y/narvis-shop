# Next.js 이전 — 브라우저 수동 검증 체크리스트

> 전환(5단계) 전 마지막 관문. `curl`로는 확인할 수 없는 것만 모았다.
> 계획서: `docs/nextjs-migration.md` · 라우트별 요약표는 그 문서 4단계 게이트 참조

## 준비

원본 dev 서버(3000)를 내리고 Next를 3000에 올린다 — 백엔드 CORS가 `http://localhost:3000`만 허용한다.

```bash
# 원본 dev 서버가 떠 있으면 먼저 종료 (Ctrl+C)
cd jarvis-web-next
npm run dev     # → http://localhost:3000
```

원본으로 되돌리려면 이 서버를 끄고 레포 루트에서 `npm run dev`. 원본 파일은 그대로 있다.

---

## A. 최우선 — 이식하며 **구조가 바뀐** 곳

여기서 문제가 나올 확률이 가장 높다. 원본과 다른 메커니즘을 쓴다.

### A-1. 결제 흐름 (원본 `location.state` → sessionStorage)
- [ ] 상품 상세에서 **바로 구매** → `/checkout`에 **상품·수량·옵션이 표시**되는가
      *(빈 화면이면 state 전달 실패)*
- [ ] 장바구니에서 선택 후 **주문하기** → `/checkout`에 선택 상품만 넘어오는가
- [ ] 결제 완료 → `/checkout/complete`에 **주문번호·상품·금액**이 표시되는가
- [ ] 완료 화면에서 **뒤로가기** → 결제 화면으로 돌아가 중복 결제되지 않는가
      *(replace 이동이라 히스토리에 없어야 정상)*
- [ ] `/checkout`에 **주소창으로 직접 진입** → "주문 정보 없음" 안내가 뜨는가(빈 화면·에러 아님)

### A-2. 세션 복원 (AT 메모리 보관)
- [ ] 로그인 → **새로고침(F5)** → 로그인 상태가 유지되는가
- [ ] 로그인 → 새로고침 직후 **로그인 화면으로 튕기지 않는가**
      *(`isAuthReady` 판정이 깨지면 여기서 튕긴다)*
- [ ] 로그아웃 → 새로고침 → 게스트 상태 유지, 콘솔에 401 반복 없는가

### A-3. 가드 (Outlet → children, 이펙트 리다이렉트)
- [ ] 게스트로 `/mypage/orders` 접근 → `/login?returnUrl=...`로 이동하는가
- [ ] 로그인 후 **원래 가려던 페이지로 복귀**하는가
- [ ] 게스트로 `/checkout` 접근 → 로그인 유도
- [ ] 일반 회원으로 `/seller` 접근 → 홈으로 튕기는가
- [ ] **판매자 계정**으로 `/`(홈) 접근 → `/seller`로 격리되는가

## B. SSR·URL 관련 — 이번에 새로 생긴 동작

### B-1. 챗봇 (`?q=` 처리 방식 변경)
- [ ] 홈 히어로에서 질문 입력 → `/chat`으로 이동하며 **그 질문이 자동 전송**되는가
- [ ] 답변이 **한 글자씩** 그려지는가 *(한 덩어리로 튀어나오면 스트리밍 깨진 것)*
- [ ] 전송 후 주소창에서 **`?q=`가 사라지는가** *(새로고침 시 재전송 방지)*
- [ ] 조건 칩 **X 제거** 동작
- [ ] 챗봇 카드 → 상품 상세 진입 시 **즉시 렌더**되는가(캐시 시딩)
- [ ] 챗봇에서 장바구니 담기 → **헤더 뱃지 숫자**가 바로 오르는가

### B-2. 브랜드 필터 (useState → URL 쿼리)
- [ ] 정렬 변경 → **주소창에 `?sort=`가 붙고** 목록 순서가 바뀌는가
- [ ] 카테고리 칩 선택 → `?category=` 반영
- [ ] **뒤로가기** → 이전 필터 상태로 돌아가는가
- [ ] 필터 건 URL을 **새 탭에 붙여넣기** → 같은 화면이 뜨는가
- [ ] 필터 변경 시 **스크롤 위치가 유지**되는가(맨 위로 튀지 않음)

### B-3. 상품 상세 SSR
- [ ] 상세 진입 시 **깜빡임 없이** 바로 내용이 보이는가
- [ ] 옵션 선택 → 가격 반영 → 장바구니 담기
- [ ] 찜 버튼 토글 *(게스트는 로그인 유도)*
- [ ] 없는 상품 URL(`/products/99999999`) → **404 화면**

## C. 나머지 화면 — 원본과 동일해야 함

- [ ] `/` 인기·추천 상품 렌더, 카테고리 그리드 클릭 → 챗봇 이동
- [ ] `/cart` 게스트 담기, 수량 변경 시 헤더 뱃지 동기화
- [ ] `/wishlist` 게스트 → 로그인 유도 / 회원 → `/mypage/wishlist`로 이동
- [ ] `/mypage/*` 주문 목록·상세, 리뷰 작성, 배송지 추가·수정, 취소·반품
- [ ] 마이페이지 **좌측 메뉴 활성 표시**가 현재 화면과 맞는가 *(NavLink 치환)*
- [ ] `/seller/*` 대시보드·주문·상품 목록, **헤더 메뉴 활성 표시**
- [ ] 셀러 AI 챗 스트리밍
- [ ] `/inquiry` `/admin` "준비 중" 표시

---

## D. 반응형 (모바일 우선 — 프로젝트 필수 규칙)

- [ ] 브라우저 폭을 **360px**로 줄여 주요 화면 확인: 홈 · 상세 · 장바구니 · 결제 · 마이페이지
- [ ] **가로 스크롤이 생기지 않는가**
- [ ] 마이페이지 좌측 메뉴가 모바일에서 가로 스크롤 필로 바뀌는가

---

## E. 콘솔 (전 과정에서 열어둘 것)

- [ ] **하이드레이션 불일치 경고**가 없는가
      *(sessionStorage·window를 읽는 곳에서 나기 쉽다 — 결제·챗봇 화면 주의)*
- [ ] 401이 반복해서 찍히지 않는가
- [ ] React key 경고, 무한 렌더 경고 없는가

---

## 문제 발견 시

화면·동작·콘솔 메시지를 알려주면 고친다. 지금은 원본 앱이 그대로 배포 중이라 **급하지 않다** — 여기서 다 잡고 전환하는 게 목적이다.

전부 통과하면 계획서 5단계의 "남은 것 — 실제 전환" 절차로 진행.
